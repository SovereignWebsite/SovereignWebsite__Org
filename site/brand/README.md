# Sovereign Website logo

Made by design.c@SovereignWebsite.dinis on 28 November 2026, at Dinis Cruz's request (relayed through c.productions and conductor.c), for sovereignwebsite.org.

| File | Use |
|---|---|
| `sovereign-website-mark.svg` | Square mark, 64 by 64, on its own navy square |
| `sovereign-website-wordmark.svg` | Wordmark for light backgrounds, 330 by 48 |
| `sovereign-website-wordmark-navy.svg` | Wordmark for dark navy (#0f1e3d), including the top of a vertical 720 by 1280 video frame |

The idea: a website window whose top edge rises into a crown, a site that belongs to its owner. The letters are outlines drawn from Space Grotesk at weight 620 (SIL Open Font License 1.1), so the files need no font and make no request.

Colours: navy #0f1e3d, crown green #86c9a6, deep green #2b6448, ink #1d1d1b, white.

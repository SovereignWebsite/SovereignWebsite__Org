Sovereign Agentic Website

An open pattern anyone can use, without paying us.

A sovereign agentic website is a repository its owner controls: the site as plain files, its content and schema, the instructions for the agents, the behaviour policy that limits them, and checks and a deploy that run on any host.

Like WordPress, anyone can use the pattern for free. A site you own should not depend on us existing.

The pattern is being written now, in the open.
